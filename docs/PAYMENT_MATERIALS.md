## 先选真实状态

支付宝 H5 表单里的「手机网站状态」必须与事实一致：

- **当前应选「未上线」**，除非 `xuyueji.cn` 已完成备案、部署并可被公网访问。
- 选择「未上线」会限制收款额度与产品使用有效期，这是平台规则，不能用截图或文案绕过。
- 取得 ICP / AI 服务相关手续、部署上线并完成商户准入后，再补全信息。

本仓库截图来自本地运行的真实页面，**不证明**站点已上线、商户已签约或支付已开通。

## 重新生成

```bash
# 全部 E2E + 桌面/手机截图
pnpm e2e

# 只生成手机 H5 三张
pnpm screenshots:h5
```

截图输出在 `artifacts/screenshots/`，该目录被 `.gitignore` 忽略，不会进入公开仓库；
需要上传时从本地取文件。

## 审核前还要准备

- 可公网访问的正式 URL（备案完成后）。
- 运营主体、ICP 备案号、客服渠道与隐私/服务协议正式版本。
- 支付宝要求的经营内容说明；本项目的经营内容是数字内容/积分充值与 AI 文本服务。
- **不要**把「支付未开通」的页面描述成已开通支付；也不要用本地截图冒充线上站点。
