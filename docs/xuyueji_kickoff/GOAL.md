# GOAL — 产品目标和不可妥协原则

## 定位

续月记是面向中国大陆成年用户的 AI 文本互动、长篇角色扮演和文学创作工具，重点承接从 DeepSeek 客户端迁移的历史对话；不是 DeepSeek 官方产品，也不提供规避模型审核的“无限制”服务。

## 目标用户/JTBD

- 文游/角色扮演：将已有对话、角色、世界书、预设无损迁来，并持续推进剧情。
- 梦向/乙游代入（成年人）：需要角色一致性、身份设定、多版本剧情与私密性。
- 小说创作者：需要多故事管理、章节整理、检索、导出、可解释的 Prompt 和费用。
- 酒馆资深用户：需要成熟编辑器、兼容格式、高级宏/正则、分支与群聊，而不是只有聊天输入框。

## 六个产品原则

1. **完整酒馆**：V1.0 功能规格覆盖常见文本酒馆内核，不把核心功能移到 V2。
2. **用户资产可带走**：云端主存档、离线可读缓存、可移植 ZIP/JSONL/角色卡导出；不得制造数据锁定。
3. **按量透明**：展示计费规则、实际 Token 和每次积分变化；余额和订单由服务端决定。
4. **隐私优先**：私有角色、私聊默认不公开；后端最小化原始 Prompt 日志；授权访问与审计。
5. **兼容但不盲复制**：支持 Tavern Character Card V2/V3（含 PNG/JSON 与未知字段保留策略），测试导入导出；审查外部 GPL/AGPL 代码许可证。
6. **业务真实与合规**：任何官网/支付截图与实际服务一致；上线前完成适用手续；不让脚本、预设、客户端选项绕开服务端安全控制。

## 产品发布目标（非性能承诺）

- 以手机 Web 为一等公民，桌面高级酒馆编辑也可用。
- 生成结束后聊天存档和费用记录正确，无双重扣费；失败路径可恢复或明确人工介入。
- 真实用户可完成：导入历史 → 配人设世界书 → 聊天分支/记忆 → 换设备接着聊 → 完整导出 → 查看精确消耗。
- 构建产物可在单台 2C/2GiB/3Mbps ECS 上部署；对资源和并发设限，不宣称未知容量。

## V1.0 边界

**V1.0 内**：完整文本酒馆、兼容导入导出、可选媒体附件/头像展示、浏览器朗读与外部供应商接口、云端同步、充值/余额/订单、管理与风险治理、访问性与国际化准备。
**不强求首发上线的外部经营能力**：开放第三方角色市场、第三方商户入驻、用户间积分转移、未经签约的生图/语音供应商付费能力、公开多人协同编辑。同类编辑/适配接口仍应为未来保留扩展位。

## 非目标

- 不做非官方消费端 API 反向代理、额度共享/账号池或绕过官方内容审核。
- 不将用户自带角色脚本直接在服务器执行 JavaScript。
- 不承诺永久无损模型记忆（完整存档≠无限模型上下文）。
- 不承诺审核通过或许可必然获批。
