# 安全、合规与运维基线

## 启动前的监管 Gate

ICP备案已经提交 ≠ AI 服务登记/拟人化互动安全评估/算法备案/支付产品获批。根据正式业务和主管部门意见办理对应事项；首次公众开放前确认结果、上链完整服务协议和真实运营主体。任何 M0 支付截图均不得伪造资质或真实支付状态。

## 用户隐私与安全

- 明示 AI 身份及第三方 DeepSeek 数据处理；不把私人聊天做成公开内容、不用于未经授权的训练/营销。
- 自有平台管理员默认无业务读取私聊正文权限；极少数依法必要的排障/风险处置需要工单审批、最小授权与审计。
- 强制对象级授权检查，所有 API 按 owner 校验；防 IDOR；导出/删除 API 同样需要二次认证及速率限制。
- 身份验证使用成熟会话库，HttpOnly/Secure/SameSite Cookie，CSRF 防护、密码哈希、登录速率限制、会话撤销；不在 localStorage 存敏感 Token。
- 上传角色卡/附件/ZIP 限速限大小，文件类型嗅探、解压炸弹/路径穿越防护、图像处理与元数据清理；外部文本禁止执行任意 JS。
- 富文本渲染做 HTML sanitization，CSP 限制外链脚本。Webhook 采用服务端签名验证，不接受前端“我已支付成功”的信号。
- AI 模型安全级别后端不可变；敏感内容拒绝的结果不作为可发布的最终消息；配置投诉、申诉、年龄保护、连续使用提醒、AI 内容标识与停服告知流程。

## 基础设施（ECS）

- SSH 公钥已配置；后续创建非 root sudo 用户并验证，再禁密码认证；SSH 安全组仅可信 IP，80/443 公网，Postgres 和后端业务端口只在内网。
- 新 ECS 若与 ArtFlow 共用安全组，应拆分规则避免误影响旧项目。Ubuntu 安全更新、NTP、登录审计、磁盘监控和定期备份。
- `secrets` 放容器 secret 或主机权限严格的 env 文件；永不提交 API Key、支付宝私钥、用户数据至 Git。
- 管理端权限分离：账务、客服、风控操作角色不同；至少每个高危动作二次确认+审计。

## 观测与告警

指标：请求成功率、上游状态码、stream 断开率、`unknown_usage` 数、每次生成 Token 分布、缓存命中、可用积分及总冻结、充值回调异常、DeepSeek API 余额、DB 空间/WAL、CPU/memory/outgoing Mbps。
日志默认仅记录 run_id、user pseudonym、错误类型、延迟和计费摘要，不含完整 Prompt/消息正文/密钥/支付敏感字段。

## 低成本备份

- `pg_dump` 定时 + 备份完整性检查 + 加密异地存储；每周最少演练一份恢复到隔离数据库（频率可据运营期调整）。
- 文件资产按 hash 清单同步到异地；所有备份考虑业务删除和密钥管理。
- 若只有本机备份不能称为灾难恢复。2GiB 服务器做导出时要限并发/流式处理。

## 法律政策记录

由运营者确认浙江网信相关应用登记与拟人化互动安全评估、算法备案，支付宝网站支付实际类目与签约许可，ICP 备案结果，公安联网备案及 AI 生成内容标识要求。文档中的检查项不构成法律意见或审批结果。
