## 关键体验流程（桌面与手机均需验收）

A. 新用户：注册 → 了解价格 → 选择原生对话/导入旧记录 → 创建角色 → 使用少量测试额度 → 看到费用 → 导出。
B. 资深酒馆用户：V3 PNG 人物卡 + 内嵌 lorebook → 设置 Persona → 预设排序 → 正则预览 → 触发世界书 → 群聊 → 生成 Swipe → 分支继续 → ZIP 导出回导。
C. 老用户换机：登录 → 分页加载同一角色/分支 → 编辑角色时遇到冲突提示 → 继续并最终确认云端版本。
D. 支付与故障：支付通知重放无重复入账；余额不足不发起请求；DeepSeek 402/429/断流没有虚假的成功消息。

## UI 页面

`/` 官网；`/chat` 主聊天；`/characters` 角色；`/lorebooks` 世界书；`/presets` 预设/宏/正则；`/memories` 记忆；`/wallet` 充值/消费/退款；`/settings` 同步/导入导出/隐私；`/admin` 后台；`/help` 帮助；`/terms`, `/privacy`, `/refunds`, `/contact`。
