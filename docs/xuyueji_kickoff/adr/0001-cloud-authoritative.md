# ADR-0001 云端权威 + 本地缓存 + 可移植文件

状态：Accepted（架构基线）

决策：PostgreSQL 是云端存档权威，Dexie 是浏览器缓存/草稿/outbox；服务器定义增量同步游标、版本和冲突处理；ZIP 是用户可移植的内容文件库。

原因：用户主要在手机/PC 间切换；纯浏览器数据无法可靠跨端迁移和恢复；服务器已有 PostgreSQL 运维经验，文本成本可控。

替代：纯 IndexedDB 省服务器但容易清理丢失；服务器 JSONL 简单但多用户事务与搜索成本高；CRDT 协同过度设计。

边界：真实文件夹需用户明确授权，不承诺网页静默写入用户 `~/.xuyueji`。云端保存会增加运营者的数据保护义务。
